用法

HTML 
<!-- 引入 src/liquid-glass-toggle.css 后 -->
<label class="lg-switch">
  <input type="checkbox" checked aria-label="开关" />
  <span class="lg-switch__track">
    <span class="lg-switch__thumb"></span>
  </span>
</label>
自定义 
/* 强调色 */
.lg-switch { --lg-accent: rgba(10, 132, 255, 0.6); }

/* 任意尺寸：只需给宽度 / 高度 / 滑块宽度，位移与形变自动推导 */
.lg-switch--xl {
  --lg-w: 200px;
  --lg-h: 116px;
  --lg-thumb-w: 116px;
}

实现要点

两段式时序

位移先走 0.35s 弹簧曲线，宽高形变延迟 0.22s 才发生——这就是"液体被拖拽后回弹"的观感来源。

轮廓贴合

outline-offset 取负值让描边画在元素内侧，形变时描边随形状一起收缩，不会溢出。

压力玻璃

按下时 backdrop-filter 从无到 blur(24px) saturate(160%)，配合多层 inset 高光透出底层壁纸。

尺寸自推导

位移 = 宽 − 滑块宽 − 内边距×2，按下位移 = 位移 − 6px，所有变体共用一套公式。

原生可访问

真实 checkbox 驱动，键盘 Tab / 空格可用，focus-visible 有独立焦点环。

降级与省电

不支持 backdrop-filter 时回退实色底；prefers-reduced-motion 下关闭形变过渡。
